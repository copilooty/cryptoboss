Как я собрал CryptoBoss

Из описания CryptoBoss я собрал браузерную игру с комнатами для друзей, ходами, рынком, участками и майнингом. Исходного кода и полного свода правил не было, поэтому правила этой версии — рабочее приближение, а не точная копия настольной игры.

01 / Сборка

От фотографий к игре в браузере

  1. Собрал механику из описания

    В исходной папке были только эта страница и видео, без исходников игры или полного свода правил. В качестве основы взял 24 клетки, кубик, очередь ходов, крипторынок и майнинг.

  2. Придумал дизайн сайта

    Выбрал тёмный фон, цветные клетки, яркие кнопки и отдельные панели для биржи, фермы и истории. Цвет помогает быстро отличить фишки и найти нужное действие.

  3. Связал интерфейс с сервером

    Добавил комнаты с приглашением, очередность ходов и сохранение партии. Сервер проверяет сделки и определяет победителя по итоговому капиталу.

02 / Технологии

На чём работает игра

HTML
Разметка лобби и игрового экрана.
CSS
Палитра, игровое поле и раскладка для телефона и ПК.
JavaScript
Обрабатывает кнопки, отправляет запросы и обновляет экран.
Node.js
Создаёт комнаты, проверяет ходы и применяет правила на сервере.
WebSocket / JSON
Синхронизирует игроков и сохраняет состояние партии на сервере.
  1. 01 · Браузер

    Игрок нажимает «Бросить кубик хода». JavaScript отправляет запрос.

  2. 02 · Сервер

    Node.js проверяет очередь, рассчитывает результат и сохраняет комнату в JSON-файл.

  3. 03 · Экран игры

    Браузер получает состояние партии и показывает обновлённую позицию фишки.
