# CryptoBoss Online

Браузерная многопользовательская версия CryptoBoss. Игроки входят по коду комнаты; сервер проверяет ходы и сохраняет комнаты и партии на диск.

## Запуск

Нужен Node.js 18 или новее.

```sh
npm install
npm start
```

Откройте `http://localhost:3000`. Для игры с друзьями из разных сетей сервер должен быть доступен в интернете; GitHub сам по себе его не запускает.

## Публикация на Render

В корне проекта есть `render.yaml` с настройками бесплатного Node.js-сервиса:

Игра уже опубликована: https://cryptoboss-axrz.onrender.com/

Чтобы развернуть свой экземпляр, войдите в Render, выберите **New → Blueprint** и укажите репозиторий `copilooty/cryptoboss`. Проверьте конфигурацию `cryptoboss`, нажмите **Apply** и откройте выданный Render URL.

Создатель комнаты отправляет друзьям ссылку-приглашение — играть можно из разных сетей.

Бесплатный сервис может засыпать после бездействия и перезапускаться. В этом варианте активные комнаты и сохранённые партии могут пропасть при перезапуске: файловая система бесплатного сервиса не предназначена для постоянных игровых сохранений. Для сохранения комнат после перезапуска нужен сервис с постоянным диском, подключённым к каталогу `data` (такая конфигурация может требовать платный тариф). Сама игра для всех участников работает на одном запущенном сервере, WebSocket-соединение поддерживается.

## Игровой прототип

В репозитории до реализации была только страница-описание проекта и видеозапись, но не исходные правила, поле или сервер. Поэтому текущая партия — самостоятельное восстановление по описанию, а не подтверждённая копия настольной игры 1:1.

Из описания перенесены поле на 24 клетки, бросок кубика, рынок, криптоактивы, участки, майнинг, комнаты с приглашением, очередь ходов, сохранение игры и подсчёт капитала. Неуказанные значения и правила приняты как игровые допущения: стартовый капитал 1 200 USDT, цены участков и рента из `game-rules.js`, доход майнинг-установок 25 USDT за ход и окончание после 16 раундов. Они могут отличаться от оригинала и вынесены в одно место для настройки.
